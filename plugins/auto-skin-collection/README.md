# Auto Skin Collection Completer

Work through selected collections on farm accounts from **Farming → Skin Collections**. Requires Hub 1.2.8 or newer.

1. Choose accounts and enter the exact names shown on the game's Skin Collection page.
2. Set the submission value limit and choose how to fill gaps. Use **Submit from inventory** for existing skins, **Also open owned cases** to draw from case stock, or **Also buy and open within budget** with an explicit spend cap and cash reserve.
3. Run **Preview**. For a one-off batch, choose **Live** with **On** off, preview again and confirm. For recurring runs, choose **Live**, switch **On** on and set the interval. **Practice** gives a read-only preview.

Collection submissions consume one skin from the specified group. The game chooses the physical copy. The preview gives the maximum value and the number of eligible copies. The plugin rechecks those copies, skips favourites and withholds a group if the full candidate set is unavailable or exceeds the value cap. It verifies progress before claiming a completed reward.

Case buying follows the live shop quote and set limits. Quick openings keep the drops. A later scan can submit those drops. Opening supply depends on the case stock and the standard case and collection shops. Interrupted or unconfirmed writes require review before automation can continue.
