Missions

What it does

Missions polls each healthy account, claims eligible mission rewards, and displays progress in a Missions tab and account-card badges.

How it uses the farmer

Uses staggered per-account scheduling and clears the cached account view when a run stops.

Publisher catalog

The signed catalog lists version 1.1.0, which requires core 1.0.6. Install or update publisher plugins from the app’s Plugins tab.
