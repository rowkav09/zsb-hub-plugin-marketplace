Monthly pass

Claim monthly pass rewards from the free track, Pro track or both.

What it does

Monthly pass checks selected clicking accounts on an interval and claims eligible tiers for the configured track.

How it uses the farmer

Uses the host account selector and a separate claiming switch. The Pass tab reports each account’s progress.

Publisher catalog

The signed catalog lists version 1.3.0, which requires core 1.0.6. Install or update publisher plugins from the app’s Plugins tab.
