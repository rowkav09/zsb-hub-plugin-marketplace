Proxy manager

Configure and test proxy or WireGuard routes for the farmer.

What it does

Proxy manager publishes routes to the core, checks reachability and lets the user pin accounts to a route.

How it uses the farmer

Uses the host’s routing API and secret storage. WireGuard uses a local SOCKS bridge. Routes with a shared known exit IP share their capacity.

Publisher catalog

The signed catalog lists version 1.1.0, which requires core 1.0.6. Install or update publisher plugins from the app’s Plugins tab.
