What it does

Opener can buy stock within a budget or use existing stock. It can handle drops, favourite rules and boosting effects. It tracks account XP and rank changes.

How it uses the farmer

Uses account busy markers during turns. The inspected beta also supports a Discord webhook for favourited drops when configured by the user.

Publisher catalog

The signed catalog lists version 1.6.0, which requires core 1.2.3. Install or update publisher plugins from the app’s Plugins tab.
