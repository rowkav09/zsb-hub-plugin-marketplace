What it does

Account Pulse is a read-only dashboard for account health. It lists the accounts known to the farmer and can hide stopped accounts from the table.

How it uses the farmer

Reads the cached account list and registers a settings toggle, tab, table and summary action. This plugin makes zero site requests.

ZIP import

This package is unsigned. Review the source, then use Plugins → Custom plugins → Import .zip with Allow unverified plugins enabled. Installation guide
