What it does

Trader coordinates sender and receiver sockets. Both accounts must be in ZSB Hub and clicking. The plugin supports a practice mode and receipt checks.

How it uses the farmer

Serializes work per sender and receiver, and uses handoff requests when Armory is using an account needed for a route.

Publisher catalog

The signed catalog lists version 1.5.0, which requires core 1.2.2. Install or update publisher plugins from the app’s Plugins tab.
